# Security

Report vulnerabilities privately to savagetism@icloud.com — do not open
public issues for exploitable weaknesses.

Scope: dual-signature IOU verification, invocation-to-IOU binding, settlement arithmetic (over-settlement refusal), book hash-chaining, derived-balance correctness.

Out of scope: the semantic value of compute units (a deployment decision), the treaty referenced by an IOU (that is wolakota's scope), and counterparty solvency (see THREAT_MODEL.md).
